# Настройка CI/CD для vueapp.itcenter.pro

## Быстрая настройка

### 1. Добавьте Secrets в GitHub

Перейдите в ваш репозиторий на GitHub:
1. Откройте **Settings** → **Secrets and variables** → **Actions**
2. Нажмите **New repository secret**
3. Добавьте следующие secrets:

#### Обязательные secrets:

| Имя | Значение |
|-----|----------|
| `FTP_SERVER` | `vueapp.itcenter.pro` |
| `FTP_USER` | `vueapp_itcen_usr` |
| `FTP_PASSWORD` | `,u{,%qpfHr|qH`1(` |

#### Опциональные secrets:

| Имя | Значение | Описание |
|-----|----------|----------|
| `FTP_SERVER_DIR` | `/public_html` | Путь на FTP сервере для деплоя (обычно `/public_html`, `/www` или `/htdocs`) |
| `FTP_PORT` | `21` | Порт FTP сервера (по умолчанию 21) |

**Примечание:** Путь `FTP_SERVER_DIR` должен начинаться с `/` (например, `/public_html`). Если путь отличается, уточните у хостинга правильный путь.

### 2. Автоматический деплой

После настройки secrets деплой будет происходить автоматически при каждом push в ветку `main` или `master`.

### 3. Ручной запуск деплоя

Если нужно запустить деплой вручную:

1. Перейдите в **Actions** в репозитории
2. Выберите workflow **Deploy to Server**
3. Нажмите **Run workflow**
4. Выберите ветку и нажмите **Run workflow**

### 4. Проверка работы

После деплоя проверьте:
- Главная страница: https://vueapp.itcenter.pro/
- Страница установки: https://vueapp.itcenter.pro/install.php

## Что делает CI/CD

1. ✅ Проверяет код из репозитория
2. ✅ Устанавливает зависимости (`npm ci`)
3. ✅ Собирает проект (`npm run build`)
4. ✅ Копирует файлы из `dist/` на сервер через FTP
5. ✅ Синхронизирует файлы (удаляет старые, добавляет новые)

## Устранение проблем

### Ошибка подключения по FTP

- Проверьте правильность `FTP_SERVER`, `FTP_USER` и `FTP_PASSWORD`
- Убедитесь, что FTP доступен на сервере (порт 21)
- Проверьте, что пользователь имеет права на запись в `FTP_SERVER_DIR`
- Убедитесь, что путь `FTP_SERVER_DIR` начинается с `/` (например, `/public_html`)

### Файлы не появляются на сайте

- Проверьте правильность пути `FTP_SERVER_DIR`
- Убедитесь, что файлы копируются в правильную директорию
- Проверьте логи в GitHub Actions для деталей ошибки
- Уточните у хостинга правильный путь для деплоя

### Ошибки сборки

- Проверьте логи в GitHub Actions
- Убедитесь, что все зависимости установлены
- Проверьте версию Node.js (должна быть 20.x или выше)
