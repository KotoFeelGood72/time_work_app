# Быстрая настройка SFTP секретов для GitHub Actions

## 📋 Секреты для добавления в GitHub

Перейдите: **Settings** → **Secrets and variables** → **Actions** → **New repository secret**

### Обязательные секреты (3 штуки):

| Название секрета | Значение |
|------------------|----------|
| `FTP_SERVER` | `vueapp.itcenter.pro` |
| `FTP_USER` | `vueapp_itcen_usr` |
| `FTP_PASSWORD` | `,u{,%qpfHr|qH`1(` |

### Опциональный секрет (если путь отличается):

| Название секрета | Значение | Когда использовать |
|------------------|----------|-------------------|
| `FTP_SERVER_DIR` | `/public_html/` | Если путь на сервере не `/public_html/` (должен заканчиваться на `/`) |

## ✅ После добавления секретов:

1. Перейдите в **Actions** в репозитории
2. Выберите workflow **Deploy to Server**
3. Нажмите **Run workflow** → **Run workflow**
4. Дождитесь завершения деплоя

## 🔍 Проверка:

После успешного деплоя проверьте:
- https://vueapp.itcenter.pro/
- https://vueapp.itcenter.pro/install.php

## ⚠️ Важно:

- Названия секретов должны быть **точно** такими, как в таблице (с учетом регистра)
- Не добавляйте лишние пробелы в значениях
- Пароль содержит специальные символы - скопируйте его полностью
